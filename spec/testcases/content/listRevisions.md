# 履歴を一覧する

| ID | 前提条件 | 操作 | 期待結果 |
|---|---|---|---|
| TC-content-listRevisions-01 | A は公開中で、下書きを持つ。A の履歴に、メンバー甲の下書きの保存が時点 t1 に版にした、下書きだった版 R1 と、メンバー乙の公開が時点 t2（t1 より後）に版にした、公開内容だった版 R2 がある。履歴を保持する日数は 365 | メンバーが、A の履歴を一覧する | R2、R1 の順に返す。総件数は 2。版ごとに、版の ID、版にした操作の種類、実行者の名称、日時、公開内容だった版か下書きだった版かを返す。履歴を保持する日数 365 を返す。現在の公開内容と下書きは、一覧に含めない |
| TC-content-listRevisions-02 | A の履歴に、トークンによる値の書き換えが版にした R3 がある | メンバーが、A の履歴を一覧する | R3 の実行者として、トークンを指す値（名称または発行の経路）と、発行者または紐付くメンバーの名前を返す |
| TC-content-listRevisions-03 | A の履歴に、メンバー甲が版にした R1 がある。その後、甲はメンバーの利用を解除されている | メンバーが、A の履歴を一覧する | R1 の実行者として、版にした時点の甲の名称を返す |
| TC-content-listRevisions-04 | C はごみ箱にあり、履歴の版 R1 を持つ | メンバーが、C の履歴を一覧する | R1 を返す |
| TC-content-listRevisions-05 | A の履歴の版 R1 は、履歴の版の整理で削除されている | メンバーが、A の履歴を一覧する | R1 を含めない |
| TC-content-listRevisions-06 | A は完全削除されている | メンバーが、A の履歴を一覧する | `NotFoundError` を返す |
| TC-content-listRevisions-07 | A の履歴の版は R1 だけ。その後、スキーマの反映の移行が、A の公開内容、下書き、R1 の値を変換した | メンバーが、A の履歴を一覧する | R1 だけを返す。総件数は 1。R1 の、移行で変換された日時と、変換後のスキーマの版を返す |
