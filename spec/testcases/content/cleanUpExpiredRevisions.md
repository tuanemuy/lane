# 期限を過ぎた履歴の版を削除する

| ID | 前提条件 | 操作 | 期待結果 |
|---|---|---|---|
| TC-content-cleanUpExpiredRevisions-01 | 履歴を保持する日数は 365。A は公開中で、下書きを持つ。A の履歴に、400 日前に版にした R1 と、10 日前に版にした R2 がある | 定期ジョブが、そのワークスペースの履歴の版の整理を行う | R1 を削除し、R2 は残る。A の公開内容と下書きは変わらない。削除した版の件数 1 を返す |
| TC-content-cleanUpExpiredRevisions-02 | 100 日前に版にした R1 がある。その後、保持方針を、履歴 365 日から 90 日に変更している | 定期ジョブが、そのワークスペースの履歴の版の整理を行う | R1 を削除する |
| TC-content-cleanUpExpiredRevisions-03 | 期限を過ぎた履歴の版は無い。期限を過ぎたごみ箱のコンテンツ C1 がある | 定期ジョブが、そのワークスペースの履歴の版の整理を行う | 何も削除しない。削除した版の件数 0 を返す。C1 はごみ箱に残る |
| TC-content-cleanUpExpiredRevisions-06 | 前の起動が途中で中断し、期限を過ぎた版の一部を削除済み。残りの期限を過ぎた版が残っている | 定期ジョブが、そのワークスペースの履歴の版の整理を行う | 前の起動が削除した版は戻らない。残りの期限を過ぎた版を削除する |
| TC-content-cleanUpExpiredRevisions-07 | ワークスペース W1 と W2 が、それぞれ期限を過ぎた版を持つ | 定期ジョブが、W1 を対象に履歴の版の整理を行う | W1 の期限を過ぎた版だけを削除する。W2 の版は変わらない |
| TC-content-cleanUpExpiredRevisions-08 | 期限を過ぎた版 R1 だけが、メディア Md を使う | 定期ジョブが、そのワークスペースの履歴の版の整理を行う | R1 を削除する。Md の使用箇所に、R1 が現れない |
| TC-content-cleanUpExpiredRevisions-09 | 定期ジョブが期限を過ぎた版 R1 を読んだ後、削除する UnitOfWork の確定までに、ほかの操作が R1 を削除した | 定期ジョブが、そのワークスペースの履歴の版の整理を行う | `ConflictError`（`REVISION_MISSING`）で終える。その UnitOfWork は何も削除せず、残りは次の起動が整理する |
| TC-content-cleanUpExpiredRevisions-10 | 期限を過ぎた版 R1 がある。スキーマの反映が適用中 | 定期ジョブが、そのワークスペースの履歴の版の整理を行う | エラーにせず、何も削除せずに起動を終える。削除した版の件数 0 を返す。R1 は残り、反映が終わった後の起動が整理する |
