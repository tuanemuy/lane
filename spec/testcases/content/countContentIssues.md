# モデルごとの入力エラーと制約違反の件数を確認する

| ID | 前提条件 | 操作 | 期待結果 |
|---|---|---|---|
| TC-content-countContentIssues-01 | モデル M1 に、下書きが入力エラーを持つ A と B、公開内容が現行の制約を満たさない C がある。モデル M2 のコンテンツは、どれも入力エラーも制約違反も持たない | メンバーが、件数を確認する | M1 は、入力エラーを持つ下書き 2 件、制約を満たさない公開内容 1 件。M2 は、どちらも 0 件 |
| TC-content-countContentIssues-02 | M1 に、下書きが入力エラーを持つ A がある。メンバーは、M1 を「下書きの入力エラーあり」で絞り込んで一覧すると、総件数 1 を得る | メンバーが、件数を確認する | M1 の入力エラーを持つ下書きの件数は 1。一覧の総件数と同じ |
| TC-content-countContentIssues-03 | M1 の D はごみ箱にあり、下書きが入力エラーを持つ。M1 に、ほかのコンテンツは無い | メンバーが、件数を確認する | M1 は、どちらも 0 件 |
| TC-content-countContentIssues-04 | 現行スキーマに、モデルが無い | メンバーが、件数を確認する | エラーにしない。空の一覧を返す |
