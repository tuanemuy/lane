# 期限を過ぎたごみ箱のコンテンツを完全削除する

| ID | 前提条件 | 操作 | 期待結果 |
|---|---|---|---|
| TC-content-purgeExpiredTrash-01 | ごみ箱を保持する日数は 30。40 日前に移動した C1 と、5 日前に移動した C2 がごみ箱にある。C1 は、履歴の版を持ち、メディア Md を使う | 定期ジョブが、そのワークスペースのごみ箱の完全削除を行う | C1 を、下書きと履歴の版とともに完全削除し、C2 は残る。完全削除したコンテンツの件数 1 を返す。Md は残る。C1 の下書きと履歴の版のメディアの使用箇所は無くなる。公開の変更の記録を追記せず、`content.publication_changed` を記録しない |
| TC-content-purgeExpiredTrash-02 | 40 日前に移動した C1 と C3 がごみ箱にある。通常の管理対象の D が、下書きの必須の参照で C1 を参照する。C3 は参照されていない | 定期ジョブが、そのワークスペースのごみ箱の完全削除を行う | エラーにしない。C1 はごみ箱に残り、C3 を完全削除する。完全削除したコンテンツの件数 1 と、参照されているためごみ箱に残したコンテンツの件数 1 を返す。D は変わらない |
| TC-content-purgeExpiredTrash-04 | 40 日前に移動した C1 がごみ箱にある。通常の管理対象の G が、下書きの任意の参照で C1 を参照する | 定期ジョブが、そのワークスペースのごみ箱の完全削除を行う | C1 を完全削除する。G は残り、G の下書きは変わらない |
| TC-content-purgeExpiredTrash-05 | 40 日前に移動した C1 がごみ箱にある。C1 のモデルは非推奨 | 定期ジョブが、そのワークスペースのごみ箱の完全削除を行う | C1 を完全削除する |
| TC-content-purgeExpiredTrash-06 | 10 日前にごみ箱へ移動した C1 がある。その後、保持方針を、ごみ箱 30 日から 7 日に変更している | 定期ジョブが、そのワークスペースのごみ箱の完全削除を行う | C1 を完全削除する |
| TC-content-purgeExpiredTrash-07 | 期限を過ぎたごみ箱のコンテンツは無い。期限を過ぎた履歴の版 R1 がある | 定期ジョブが、そのワークスペースのごみ箱の完全削除を行う | 何も削除しない。完全削除したコンテンツの件数 0 を返す。R1 は残る |
| TC-content-purgeExpiredTrash-10 | ワークスペース W1 と W2 が、それぞれ期限を過ぎたごみ箱のコンテンツを持つ | 定期ジョブが、W1 を対象にごみ箱の完全削除を行う | W1 の期限を過ぎたコンテンツだけを完全削除する。W2 のごみ箱は変わらない |
| TC-content-purgeExpiredTrash-11 | ごみ箱を保持する日数は 30。50 日前に移動した C1 と、40 日前に移動した C3 がごみ箱にある。定期ジョブが C1 を読んだ後、C1 の削除の確定までに、値の書き換えで C1 の下書きが変わった | 定期ジョブが、そのワークスペースのごみ箱の完全削除を行う | `ConflictError`（`STALE_VERSION`）で終える。C1 と C3 はごみ箱に残る |
| TC-content-purgeExpiredTrash-12 | 40 日前に移動した C1 と C2 がごみ箱にある。C1 と C2 の下書きは、互いを必須の参照で参照する | 定期ジョブが、そのワークスペースのごみ箱の完全削除を行う | エラーにしない。C1 と C2 は、どちらもごみ箱に残る。参照されているためごみ箱に残したコンテンツの件数 2 を返す |
