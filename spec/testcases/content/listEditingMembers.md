# 編集中のメンバーを確認する

| ID | 前提条件 | 操作 | 期待結果 |
|---|---|---|---|
| TC-content-listEditingMembers-01 | A に、メンバー甲（編集を始めた日時 t1）、乙（t2。t1 より後）、丙の有効な編集中の記録がある | 丙が、A の編集中のメンバーを確認する | 甲、乙の順に、それぞれの `MemberId`、名前、編集を始めた日時を返す。丙を含めない |
| TC-content-listEditingMembers-02 | A に、甲の失効した記録と、乙の有効な記録がある | 丙が、A の編集中のメンバーを確認する | 乙だけを返す |
| TC-content-listEditingMembers-03 | A に、甲の有効な記録がある。別のコンテンツ B に、乙の有効な記録がある | 丙が、A の編集中のメンバーを確認する | 甲だけを返す |
| TC-content-listEditingMembers-04 | A に、ほかのメンバーの編集中の記録は無い | 丙が、A の編集中のメンバーを確認する | 空を返す |
| TC-content-listEditingMembers-05 | 指定したコンテンツID のコンテンツが無い。そのコンテンツID の編集中の記録は無い | 丙が、そのコンテンツID の編集中のメンバーを確認する | エラーにしない。空を返す |
