# 履歴の版の削除の確認を求める

| ID | 前提条件 | 操作 | 期待結果 |
|---|---|---|---|
| TC-content-reviewRevisionDeletion-01 | A の履歴の版 R1 は、メディア Md を使い、コンテンツ T を必須の参照で参照する。A の現在の下書きも Md を使う。T を参照する内容は、R1 だけ | メンバーが、R1 を指定して削除の確認を求める | R1 の、版にした操作の種類・実行者の名称・日時、公開内容だった版か下書きだった版かを返す。R1 が使用するメディアとして Md、参照するコンテンツとして T を返す。Md は削除の後も使用され、残る使用の持ち主は A の下書きと返す。T は削除の後に参照されないと返す。A と R1 は変わらない |
| TC-content-reviewRevisionDeletion-02 | A の履歴の版 R1 と R2 は、どちらも T を本文のリンクで参照する | メンバーが、R1 だけを指定して削除の確認を求める | T は削除の後も参照され、残る参照の持ち主は A の版 R2 と返す |
| TC-content-reviewRevisionDeletion-03 | A の履歴の版 R1 と R2 は、どちらも T を本文のリンクで参照する。T を参照する内容は、ほかに無い | メンバーが、R1、R2 を指定して削除の確認を求める | T は削除の後に参照されないと返す |
| TC-content-reviewRevisionDeletion-04 | メディア Md を、A の履歴の版 R1 と、B の履歴の版 R2 だけが使う | メンバーが、R1、R2 を指定して削除の確認を求める | R1 と R2 が使用するメディアとして Md を返す。Md は削除の後に使用されないと返す |
| TC-content-reviewRevisionDeletion-05 | A の履歴に R1 がある。R2 は、履歴の版の整理で削除されている | メンバーが、R1、R2 を指定して削除の確認を求める | `NotFoundError` を返す。R2 を示す |
