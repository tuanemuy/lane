# 公開の確認を求める

| ID | 前提条件 | 操作 | 期待結果 |
|---|---|---|---|
| TC-content-reviewPublish-01 | A は未公開で、入力エラーの無い下書きを持つ。`version` は 1 | メンバーが、A を対象に公開の確認を求める | A の `version` 1 と、公開する下書きの内容を返す。違反は空。A とメディアは変わらない |
| TC-content-reviewPublish-02 | B は公開中で、下書きを持つ。下書きは、一意な項目 `slug` を「old」から「new」に変える。公開中の R が B を参照している | メンバーが、B を対象に公開の確認を求める | 公開内容と下書きの項目ごとの差分、`slug` の変更前「old」と変更後「new」、公開中の参照元として R を返す |
| TC-content-reviewPublish-03 | A の下書きは、非公開のメディア Md を使う。メンバーは、メディア公開権限を持たない | メンバーが、A を対象に公開の確認を求める | 新たに公開するメディアとして Md を返す。加わる権限（`media:publish`、メディアは Md）と、実行者に不足する権限（`media:publish`）を返す。Md は非公開のまま |
| TC-content-reviewPublish-04 | A の下書きは、入力エラーを持つ | メンバーが、A を対象に公開の確認を求める | エラーにしない。違反として、A の入力エラー（項目と理由）を返す |
| TC-content-reviewPublish-05 | A の下書きは、未公開で下書きを持つ T を参照する。T は通常の管理対象にある | メンバーが、A だけを対象に公開の確認を求める | エラーにしない。違反として、A、項目、参照先 T、理由（公開内容を持たない）を返す。T の置き場所（通常）、公開状態（未公開）、下書きの有無（あり）を返す |
| TC-content-reviewPublish-06 | A の下書きは、未公開の T を必須の参照で参照する。T は入力エラーの無い下書きを持つ | メンバーが、A と T を対象に公開の確認を求める | 違反は空 |
| TC-content-reviewPublish-07 | A の下書きの一意な項目 `slug` の値が「x」。同じモデルの公開中の B の公開内容の `slug` も「x」 | メンバーが、A を対象に公開の確認を求める | エラーにしない。違反として、A、`slug`、値「x」、相手の B を返す |
| TC-content-reviewPublish-08 | 同じモデルの A と C の下書きの `slug` が、どちらも「x」 | メンバーが、A と C を対象に公開の確認を求める | エラーにしない。A と C のそれぞれについて、`slug` の重複の違反を返す |
| TC-content-reviewPublish-09 | B は公開中で、下書きを持たない | メンバーが、B を対象に公開の確認を求める | エラーにしない。違反として、B が下書きを持たないことを返す |
| TC-content-reviewPublish-10 | A のモデルは非推奨。A の下書きは入力エラーを持つ | メンバーが、A を対象に公開の確認を求める | エラーにしない。公開できない対象として、A と、非推奨のモデルに属することを返す。違反は空で、A の入力エラーを含まない |
| TC-content-reviewPublish-11 | C はごみ箱にある。X のコンテンツは無い | メンバーが、C と X を対象に公開の確認を求める | エラーにしない。公開できない対象として、C がごみ箱にあることと、X が存在しないことを返す |
| TC-content-reviewPublish-12 | A の下書きが使う非公開のメディアの数は、`ContentBatch.maxPublishedMedia` を超える | メンバーが、A を対象に公開の確認を求める | エラーにしない。違反として、新たに公開するメディアの数と上限を返す |
