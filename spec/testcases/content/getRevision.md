# 履歴の版を取得する

| ID | 前提条件 | 操作 | 期待結果 |
|---|---|---|---|
| TC-content-getRevision-01 | A の履歴に R1 がある。R1 は、メンバー甲が時点 t1 に保存した下書きを、メンバー乙の下書きの保存が時点 t2 に版にしたもの | メンバーが、A と R1 を指定して取得する | R1 の値、版にした操作（下書きの保存）・乙の名称・t2、その内容を作った操作（下書きの保存）・甲の名称・t1、下書きだった版であることを返す |
| TC-content-getRevision-02 | A の履歴に、公開内容だった版 R2 がある | メンバーが、A と R2 を指定して取得する | R2 の値と、公開内容だった版であることを返す |
| TC-content-getRevision-03 | R9 は、別のコンテンツ B の履歴の版 | メンバーが、A と R9 を指定して取得する | `NotFoundError` を返す |
| TC-content-getRevision-04 | A の履歴の版 R1 は、履歴の版の整理または削除で無くなっている | メンバーが、A と R1 を指定して取得する | `NotFoundError` を返す |
| TC-content-getRevision-05 | A の履歴の版 R1 の値は、スキーマの反映の移行で変換された | メンバーが、A と R1 を指定して取得する | 変換後の値と、移行で変換された日時と、変換後のスキーマの版を返す |
