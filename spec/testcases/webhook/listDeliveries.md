# 通知と宛先の組を一覧する

| ID | 前提条件 | 操作 | 期待結果 |
|---|---|---|---|
| TC-webhook-listDeliveries-01 | アプリ連携の権限を持つメンバー。未公開のコンテンツの公開で作られた、宛先 A と B を持つ通知。A の送信は送信成功、B の送信は送信失敗（未対処） | 絞り込みを指定せずに一覧する | 二つの組を返す。組ごとに、通知の ID と宛先の ID、受け付けた手動再試行の回数（`retryRound`。どちらも 0）、通知の種別（公開）、確定した日時、変更した対象のコンテンツID とモデルのキー、参照元、送信結果、送信した日時、失敗の理由、未対処か対処済みか、宛先の URL を示す。秘密情報を含まない |
| TC-webhook-listDeliveries-02 | アプリ連携の権限を持つメンバー。送信待ち、送信成功、送信失敗（未対処）、送信失敗（対処済み）の組が一つずつある | 未対処に絞り込んで一覧し、対処済みに絞り込んで一覧する | 未対処の一覧は、送信失敗（未対処）の組だけを返す。対処済みの一覧は、送信失敗（対処済み）の組だけを、送信失敗として返す |

| TC-webhook-listDeliveries-07 | アプリ連携の権限を持つメンバー。一つの操作で三件のコンテンツを公開した通知が、宛先 A の送信を持つ | 一覧する | 一つの組を返す。変更した対象として、三件を示す |
