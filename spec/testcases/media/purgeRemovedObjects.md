# 消去待ちの実体を消去する（`purgeRemovedObjects`）

| ID | 前提条件 | 操作 | 期待結果 |
|---|---|---|---|
| TC-media-purgeRemovedObjects-01 | ワークスペースに、削除したメディアの消去待ちの記録（メディアの単位）が残っている。元のファイルと派生形式の実体がメディアの保管先にある | そのワークスペースを指定して実行する | そのメディアの元のファイルとすべての派生形式の実体がメディアの保管先から無くなる。記録が無くなる。消去を終えた記録の件数 1 を返す |
| TC-media-purgeRemovedObjects-02 | ワークスペースに、使わなくなった派生形式の消去待ちの記録（実体一つ）が残っている | そのワークスペースを指定して実行する | その実体だけがメディアの保管先から無くなる。同じメディアの元のファイルとほかの派生形式の実体は残る。記録が無くなる |
| TC-media-purgeRemovedObjects-03 | ワークスペースに、消去待ちの記録が無い。回収できない保管の予約と、その予約が指す確定した実体がある | そのワークスペースを指定して実行する | 実体と予約は残る。件数 0 を返す |
| TC-media-purgeRemovedObjects-05 | 利用終了の途中のワークスペースに、消去待ちの記録が残っている。実体がメディアの保管先にある | そのワークスペースを指定して実行する | その実体がメディアの保管先から無くなり、記録が無くなる。ドメインイベントを記録しない |
| TC-media-purgeRemovedObjects-06 | ワークスペースに、消去待ちの記録が 2 件ある。古い方の記録の実体の消去が失敗する | そのワークスペースを指定して実行する | 消去に成功した記録は無くなる。失敗した記録は残り、次の起動が消去する。件数 1 を返す。エラーを投げない |
| TC-media-purgeRemovedObjects-07 | ワークスペースに、消去が失敗する記録が、`BoundedDeletion.maxLimit` 件（一度の `findPending` に渡す `limit`）あり、それより新しい、消去できる記録が 1 件ある | そのワークスペースを指定して実行する | 新しい記録の実体と記録が無くなる。失敗した記録は残る |
| TC-media-purgeRemovedObjects-08 | 前の起動が実体を消去した後、記録の削除が確定せず、記録が残っている | 同じワークスペースを指定して実行する | 消去を始めから行い直し、無い実体の消去に成功して、記録が無くなる |
| TC-media-purgeRemovedObjects-09 | ワークスペースに、消去待ちの記録がある。定期ジョブが記録を読んで実体を消去した後、記録の削除の前に、同じ実体の範囲の消去待ちが改めて記録される | そのワークスペースを指定して実行する | 改めて記録された消去待ちは残る。次の起動が、その範囲の実体をもう一度消去して、記録を無くす |
