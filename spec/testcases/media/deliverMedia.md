# メディアを配信する（`deliverMedia`）

| ID | 前提条件 | 操作 | 期待結果 |
|---|---|---|---|
| TC-media-deliverMedia-01 | 公開の画像がある。アカウントは、どのワークスペースのメンバーでもない | 資格を示さずに、または、そのアカウントを添えて、元のファイルの配信先を要求する | どちらも、実体の内容、登録時の形式の種類（`contentType`）、配信の先の保持の方針 `long`（`maxAgeSeconds` は `MediaDelivery.downstreamMaxAgeSeconds`）を返す |
| TC-media-deliverMedia-02 | 公開の画像に `ready` の派生形式がある | 資格を示さずに、その派生形式の配信先を要求する | 派生形式の内容、定義の画像形式の種類、保持の方針 `long` を返す |
| TC-media-deliverMedia-03 | 非公開のメディアがある | 資格を示さずに、元のファイルの配信先を要求する | `NotFoundError` |
| TC-media-deliverMedia-04 | 非公開の画像に `ready` の派生形式がある | 資格を示さずに、その派生形式の配信先を要求する | `NotFoundError` |
| TC-media-deliverMedia-05 | 非公開のメディアがある。要求のアカウントは、そのワークスペースのメンバーで、権限を一つも持たない | そのアカウントを添えて配信先を要求する | 実体の内容、種類、保持の方針 `none` を返す |
| TC-media-deliverMedia-06 | 二つのワークスペースに、非公開のメディアが一つずつある。要求のアカウントは、一方のワークスペースだけのメンバー | そのアカウントを添えて、それぞれのメディアの配信先を要求する | メンバーであるワークスペースのメディアは、実体の内容を返す。もう一方は `NotFoundError` |
| TC-media-deliverMedia-09 | 非公開のメディアの、期限内のプレビュー用の配信先がある | 資格を示さずに、その配信先を要求する | 実体の内容、種類、保持の方針 `none` を返す |
| TC-media-deliverMedia-10 | 非公開のメディアの、期限を過ぎたプレビュー用の配信先がある | 資格を示さずに、その配信先を要求する | `NotFoundError` |
| TC-media-deliverMedia-11 | 非公開のメディアの、期限を過ぎたプレビュー用の配信先がある。要求のアカウントは、そのワークスペースのメンバー | そのアカウントを添えて、その配信先を要求する | 実体の内容、種類、保持の方針 `none` を返す |
| TC-media-deliverMedia-12 | 公開の画像の派生形式 k が、`generating` または `failed` で、変更前の派生形式を持たない | k の生成の対象の配信先を要求する | `NotFoundError` |
| TC-media-deliverMedia-13 | 公開の画像の派生形式 k が `generating` で、変更前の派生形式を持つ | 変更前の派生形式の配信先と、新しい世代の配信先を要求する | 変更前の派生形式は内容を返す。新しい世代は `NotFoundError` |
| TC-media-deliverMedia-14 | 公開の画像の派生形式 k を、定義 B の世代で生成済みにし、その配信先 u を得ている。その後に、派生形式の記録が、その世代を割り当てる前の値に戻り（復旧）、k の定義を C に変更した反映が適用され、新しい世代が生成済みになっている | 資格を示さずに、u と、取得結果が返す k の配信先を要求する | u は `NotFoundError`。取得結果が返す配信先は u と異なり、定義 C の内容を返す |
| TC-media-deliverMedia-15 | 公開の画像に `ready` の派生形式があり、資格を示さない要求に、元のファイルと派生形式の内容を返している。その後に、非公開化が確定している。アカウントは、そのワークスペースのメンバー | 資格を示さずに、同じ二つの配信先をもう一度要求する。続けて、そのアカウントを添えて同じ配信先を要求する | 資格を示さない要求は、どちらも `NotFoundError`。前の応答の内容を返さない。アカウントを添えた要求は、実体の内容、種類、保持の方針 `none` を返す |
| TC-media-deliverMedia-17 | 公開だったメディアの削除が確定している | 資格を示さずに、削除の前に得た配信先を要求する | `NotFoundError` |
| TC-media-deliverMedia-18 | 非公開のメディアの削除が確定している。要求のアカウントは、そのワークスペースのメンバー。削除の前に得た、期限内のプレビュー用の配信先がある | そのアカウントを添えて元のファイルの配信先を要求し、続けて、資格を示さずにプレビュー用の配信先を要求する | どちらも `NotFoundError` |
| TC-media-deliverMedia-19 | 登録が確定せず、確定した実体が、保管の予約または消去待ちの記録とともに残っている | その実体を指す配信先を要求する | `NotFoundError` |
| TC-media-deliverMedia-20 | 公開のメディアの記録があり、メディアの保管先に実体が無い | 配信先を要求する | `NotFoundError` |
| TC-media-deliverMedia-21 | 利用できないワークスペース（`WorkspaceAvailability.of` が偽）に、公開のメディアと非公開のメディアがある。要求のアカウントは、その区画のメンバー | そのアカウントを添えて、それぞれの配信先を要求する | どちらも `NotFoundError` |
| TC-media-deliverMedia-22 | 公開のメディアがある。配信の要求が名簿の項目、`Workspace`、メディアを読んだ後、実体を返す前に、そのメディアの非公開化が確定する。別の前提では、使用箇所の無いそのメディアの削除が確定し、確定の後の実体の消去はまだ行われていない | 資格を示さずに、元のファイルの配信先を要求する | どちらも、実体の内容、種類、保持の方針 `long` を返す。次の要求は `NotFoundError` になる |
