# メディアを取得する（`getMedia`）

| ID | 前提条件 | 操作 | 期待結果 |
|---|---|---|---|
| TC-media-getMedia-01 | メンバー。`ready`、`generating`（変更前の派生形式なし）、`failed`（理由 `processing_failed`）の派生形式を持つ公開の画像がある | その画像を取得する | 管理用の名称、検索情報、共有する説明、登録時の記録、公開範囲 `public`、メディアの `version`、元の画像の配信先を返す。`ready` の派生形式は、生成状況、画像形式、幅、高さ、配信先を返す。`generating` の派生形式は生成済みとして返さない。`failed` の派生形式は失敗の理由を返し、生成済みとして返さない |
| TC-media-getMedia-02 | メンバー。定義の変更で `generating` になり、変更前の派生形式を持つ画像がある | その画像を取得する | その派生形式の生成状況を `generating` として返す。派生形式の配信先には、変更前の派生形式の画像形式・幅・高さ・配信先を返す |
| TC-media-getMedia-03 | メンバー。共有する説明（代替テキストとキャプション）を設定したメディアと、共有する説明が未設定のメディアがある | それぞれのメディアを取得する | 設定したメディアは、現在の共有する説明を返す。未設定のメディアは、代替テキストとキャプションを未設定で返す |
| TC-media-getMedia-05 | メンバー。文書のメディアがある | その文書を取得する | 記録、説明、公開範囲、元のファイルの配信先を返す。生成状況を返さない |
| TC-media-getMedia-06 | メンバー。派生形式を定義していないスキーマのワークスペースに画像がある | その画像を取得する | 生成状況を返さない |
| TC-media-getMedia-07 | メンバー | 存在しないメディアの ID を指定して取得する | `NotFoundError` |
| TC-media-getMedia-10 | メンバー。メディアがある。取得が `Media` を読んだ後、管理情報を読む前に、そのメディアの削除が確定する | そのメディアを取得する | `NotFoundError` |
| TC-media-getMedia-11 | メンバー。現行スキーマが派生形式 a、b を定義している。画像の派生形式の記録は、a を、現行と異なる定義で `ready` に持ち、b の状態を持たない（定義の適用の前） | その画像を取得する | a と b の生成状況を `generating` として返す。a の配信先には、生成済みの a の画像形式・幅・高さ・配信先を返す。b を生成済みとして返さない |
