# ワークスペースの終了前の確認を示す（`previewWorkspaceClosure`）

| ID | 前提条件 | 操作 | 期待結果 |
|---|---|---|---|
| TC-installation-previewWorkspaceClosure-01 | `operator`。`active` のワークスペースに、未送信のフォームの通知、未対処と対処済みの送信失敗のフォームの通知、送信待ちと未対処の失敗の表示アプリへの通知、メンバー 3 人、未使用の招待 1 件、メディア 2 件がある。このワークスペースを含むバックアップが 2 件ある | そのワークスペースを指定して終了前の確認を示す | ワークスペースの ID と名称、名簿の状態（開設済み）を返す。件数の項目として、各ドメインが「利用終了の消去」に公開する項目を返す。フォームの通知の未送信と未対処の送信失敗、表示アプリへの通知の送信待ちと未対処の送信失敗は、どれも別の項目で、対処済みの送信失敗を数えない。メンバーは 3 件、未使用の招待は 1 件、メディアは 2 件。失われるデータの種類、消去する資格情報、CMS の通常データの外に残る情報として、各ドメインが「利用終了の消去」に公開する `kind` のすべてを返す。2 件のバックアップの保持・削除期限のうち遅い方の日時を返す。ワークスペースのデータは変わらない |
| TC-installation-previewWorkspaceClosure-02 | `operator`。そのワークスペースを含むバックアップが無い | 終了前の確認を示す | バックアップの保持・削除期限は `null` |
| TC-installation-previewWorkspaceClosure-03 | `operator`。利用終了が完了したワークスペース（名簿に項目が無い）がある | 存在しないワークスペース、または利用終了が完了したワークスペースの ID を指定する | どちらも `NotFoundError` |
| TC-installation-previewWorkspaceClosure-05 | `operator`。作成の途中で止まり、名簿で準備中のまま残るワークスペースがある。区画に `Workspace` は無い | そのワークスペースを指定して終了前の確認を示す | `NotFoundError` にせず、名簿の状態（準備中）と、件数が 0 の項目で、終了前の確認を返す |
| TC-installation-previewWorkspaceClosure-06 | `operator`。区画の消去が進み、名簿で終了中のまま残るワークスペースがある。一部のデータ、または区画の全部が消去済み | そのワークスペースを指定して終了前の確認を示す | `NotFoundError` にせず、名簿の状態（終了中）と、残っている件数（未完了の通知、メンバー）で終了前の確認を返す |
