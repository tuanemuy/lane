# ワークスペースの利用終了を完了させる（`completeWorkspaceClosures`）

「実体の消去を始められる」は、Media の「MediaClosure」が定める条件を、そのワークスペースが満たすことを指す。条件と、条件に要る記録は、`spec/domains/media.md` が定める。

| ID | 前提条件 | 操作 | 期待結果 |
|---|---|---|---|
| TC-installation-completeWorkspaceClosures-01 | `system`。ワークスペース A は名簿で終了中で、区画の消去を終えている。実体の消去を始められる。A のメンバーだった 1 人はワークスペース B にも所属し、もう 1 人は A だけに所属する。A には、初期構成で宣言したトークンがあった | A を指定して実行する | 利用終了が完了したことを返す。A のメディアの実体が保管先から無くなる。A は名簿から無くなり、所属の索引から A の項目が外れる。A のメンバーだったアカウントは、B にも所属するものも A だけに所属したものも、セッション、回復依頼とともに残る。A の宣言したトークンの索引の項目が無くなる。B は変わらない。A の区画には、`closed` の `Workspace` だけが残り、ほかの集約、記録、ドメインイベントは無い |
| TC-installation-completeWorkspaceClosures-03 | 上の完了の後 | 状態を確認する | 状態確認は、A を、利用終了の途中のワークスペースとして示さない |
| TC-installation-completeWorkspaceClosures-04 | `system`。名簿で終了中のワークスペースがある。区画の消去は終えている。区画に、消去待ちの実体の記録が残っていて、実体の消去を始められない | そのワークスペースを指定して実行する | 消去の進行中であることを返す。メディアの実体を消去せず、名簿から外さない。定期ジョブ「メディアの実体の消去」が記録を無くした後の起動で、完了する |
| TC-installation-completeWorkspaceClosures-05 | `system`。名簿で終了中のまま残るワークスペースがある。区画の消去が途中で止まった、または開始の確定の後、区画の消去の前に止まった（区画の `Workspace` は `closing`。`Member` と、未配送のドメインイベントと隔離されたドメインイベントが残っている）。実体の消去を始められる | そのワークスペースを指定して実行する | 区画の消去の続きを進め、区画のドメインイベントを消してから `Workspace` を `closed` にし、メディアの実体を消去して、名簿から外す。利用終了が完了したことを返す。消したイベントは配送されず、区画に、`closed` の `Workspace` のほかは、集約、記録、ドメインイベントは残らない。所属の索引に、そのワークスペースの項目は無い。アカウントは残る |
| TC-installation-completeWorkspaceClosures-07 | `system`。区画の消去が途中で止まり、名簿で終了中のまま残るワークスペースがある。実体の消去を始められない | そのワークスペースを指定して実行する | 区画の消去の続きを進め、消去の進行中であることを返す。名簿から外さない |
| TC-installation-completeWorkspaceClosures-08 | `system`。名簿で終了中のワークスペースに、メディアの記録が指さない実体が、保管先に残っている。区画の消去を終え、実体の消去を始められる | そのワークスペースを指定して実行する | その実体も保管先から無くなり、利用終了が完了する |
| TC-installation-completeWorkspaceClosures-09 | `system`。名簿で終了中で、区画の `Workspace` が `active` のワークスペースがある（利用終了が、名簿の状態の変更の後、開始の前に止まった。または、復旧の後の食い違い）。区画にデータがあり、実体の消去を始められない | そのワークスペースを指定して実行する | `Workspace` を `closing` にし、続けて区画の消去を進め、`Workspace` を `closed` にする。消去の進行中であることを返す |
| TC-installation-completeWorkspaceClosures-10 | `system`。作成の途中で利用終了を実行し、名簿で終了中のワークスペースがある。区画に `Workspace` は無い。実体の消去を始められる | そのワークスペースを指定して実行する | 開始が、区画に `closing` の `Workspace` を作り、区画の消去が `closed` にする。利用終了が完了したことを返し、名簿から無くなる |
| TC-installation-completeWorkspaceClosures-11 | `system`。名簿で終了中のワークスペース 2 つは、どちらも実体の消去を始められる。一方の区画の消去が失敗する | それぞれを指定して実行する | 失敗した側は、名簿で終了中のまま残り、次の起動が続きを進める。もう一方は、完了する |
| TC-installation-completeWorkspaceClosures-12 | `system`。名簿で準備中のワークスペース、名簿で開設済みのワークスペース、利用終了が完了したワークスペース（名簿に項目が無い） | それぞれを指定して実行する | どれも何もせずに終える。ワークスペースは変わらない |
| TC-installation-completeWorkspaceClosures-13 | `system`。名簿で終了中のワークスペースがある。区画の消去を終え（区画の `Workspace` は `closed`）、実体の消去を始められる | そのワークスペースを指定して実行する | 開始と区画の消去を、何も書かずに通過し、最後の段を確定する。利用終了が完了したことを返す。名簿に、そのワークスペースの項目は無い。区画の `Workspace` は `closed` のまま |
