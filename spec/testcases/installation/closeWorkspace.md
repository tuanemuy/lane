# ワークスペースの利用を終了する（`closeWorkspace`）

| ID | 前提条件 | 操作 | 期待結果 |
|---|---|---|---|
| TC-installation-closeWorkspace-01 | `operator`。`active` のワークスペース A に、トークン、初期構成で宣言したトークン、回答、運用設定、通知、コンテンツ、履歴の版、メディアと実体、スキーマ、操作履歴、メンバー、招待、未配送のドメインイベントと隔離されたドメインイベントがある。メンバーの 1 人はワークスペース B にも所属する。A を含むバックアップがある | A の名称を指定して利用を終了する | 消去の進行中であることを返す。A の区画のデータ（区画が記録したドメインイベントを含む）は無くなり、区画の `Workspace` は `closed` になる。消したイベントは配送されない。A は名簿で終了中のまま残る。A のメディアの実体、所属の索引の項目、宣言したトークンの索引の項目は残る。アカウントは変わらない。B のデータ、設定、トークン、メンバーは変わらない。バックアップは変わらない |
| TC-installation-closeWorkspace-02 | 上の利用終了の後（利用終了は完了していない） | A のメンバーが管理画面で A を操作する | `NotFoundError`。A は、名簿で開設済みでないワークスペースとして扱われる（「利用できるワークスペース」） |
| TC-installation-closeWorkspace-03 | `operator`。名簿で終了中で、利用終了が完了していないワークスペースがある | 同じ名称を指定して、利用終了を実行し直す | エラーにせず、同じ消去の続きを進め、消去の進行中であることを返す。名簿から外さない |
| TC-installation-closeWorkspace-04 | `operator`。作成を終え、初期所有者が未参加の（所有者の指定が `vacant` の）ワークスペースがある | その名称を指定して利用を終了する | 消去の進行中であることを返す。区画の初期所有者の招待が無くなり、区画の `Workspace` は `closed` になる。名簿で終了中になる |
| TC-installation-closeWorkspace-05 | `operator`。作成が、区画の生成の後、名簿を開設済みにする前に止まり、名簿で準備中のまま残るワークスペースがある。区画に、所有者の指定が `vacant` の `active` の `Workspace` と、作成が作った集約がある。招待は無い | その名称を指定して利用を終了する | 作成をやり直さずに、消去の進行中であることを返す。名簿で終了中になり、作成が作った集約が無くなり、区画の `Workspace` は `closed` になる。招待を発行せず、メールを送らない。定期ジョブ「利用終了の完了」が名簿から外した後、その名称でワークスペースを作成できる |
| TC-installation-closeWorkspace-06 | `operator`。作成が、名簿への登録の後、区画の生成の前に止まり、名簿で準備中のまま残るワークスペースがある。区画に `Workspace` は無い | その名称を指定して利用を終了する | 消去の進行中であることを返す。名簿で終了中になる。開始が、区画に `closing` の `Workspace` を作り、区画の消去が `closed` にする |
| TC-installation-closeWorkspace-07 | `operator`。`active` のワークスペースがある | 一致しない名称を指定して利用を終了する | `BusinessRuleError`（`WorkspaceNameMismatch`）。終了を実行せず、ワークスペースは `active` のまま、データは変わらない |
| TC-installation-closeWorkspace-08 | `operator`。利用終了が完了したワークスペース（名簿に項目が無い）がある | 存在しないワークスペース、または利用終了が完了したワークスペースの ID を指定する | どちらも `NotFoundError`。ほかのワークスペースは変わらない |
| TC-installation-closeWorkspace-10 | `operator`。`active` のワークスペースがある。区画の消去の途中で、Content の消去が失敗する | その名称を指定して利用を終了する | エラーにせず、消去の進行中であることを返す。消去を完了と示さない。ワークスペースは名簿で終了中のまま残り、区画の `Workspace` は `closing`。確定した消去は戻らない。定期ジョブ「利用終了の完了」が、続きを進める |
| TC-installation-closeWorkspace-11 | `operator`。利用終了が、名簿の状態の変更の確定の後、開始の前に止まったワークスペースがある（名簿で終了中、区画の `Workspace` は `active`） | 運営者が状態を確認し、実行し直さずに、定期ジョブ「利用終了の完了」が起動する | 状態確認は、そのワークスペースを、利用終了の途中の項目に示す。定期ジョブ「利用終了の完了」が、開始から続きを進める |
| TC-installation-closeWorkspace-12 | `operator`。`active` のワークスペースがある。利用終了が区画の `Workspace` を読んだ後、開始の確定の前に、所有者が `Workspace` を変更して確定する | その名称を指定して利用を終了する | `ConflictError`（理由 `STALE_VERSION`）をそのまま返す。開始は確定しない。名簿は終了中で、配信・受付・通知は終わっている。区画の `Workspace` は `active` のまま残り、定期ジョブ「利用終了の完了」が、開始から続きを進める |
