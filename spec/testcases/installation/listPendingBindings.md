# 紐付けを待つ運用設定を一覧する（`listPendingBindings`）

| ID | 前提条件 | 操作 | 期待結果 |
|---|---|---|---|
| TC-installation-listPendingBindings-01 | `operator`。初期構成で、フォームのキー 2 つの運用設定と、キーの集合の範囲のトークン 1 つを宣言して読み込んだワークスペース。スキーマは反映していない | そのワークスペースを指定して一覧する | 紐付けを待つフォームの運用設定 2 件（フォームのキー、受付状態、通知先、通知定義、回答の保持方針）と、範囲の紐付けを待つトークン 1 件（トークンの名称、紐付けを待つキー）を返す。秘密情報とトークンの値を含まない |
| TC-installation-listPendingBindings-02 | `operator`。宣言したキーの一つのフォームを含むスキーマの反映が確定している | 一覧する | 紐付いたフォームの運用設定と、紐付いた範囲のキーを返さない。残りの紐付け待ちだけを返す |
| TC-installation-listPendingBindings-03 | `operator`。宣言したキーがスキーマに無いまま、スキーマの反映が確定している | 一覧する | そのキーの運用設定を、紐付け待ちのまま返す |
| TC-installation-listPendingBindings-04 | `operator`。紐付け待ちのまま残っていたキーのフォームを作成する反映が、後から確定している | 一覧する | そのキーの運用設定を返さない。運用設定は、作成したフォームに紐付いている |
| TC-installation-listPendingBindings-05 | `operator`。紐付けを待つ運用設定が無いワークスペース | 一覧する | 空の列を返す。エラーにしない |
| TC-installation-listPendingBindings-06 | `operator`。ほかのワークスペースに紐付けを待つ運用設定がある | 自分が指定したワークスペースを一覧する | ほかのワークスペースの運用設定を返さない |
| TC-installation-listPendingBindings-07 | `operator`。紐付けを待つ運用設定がある、利用終了の途中のワークスペースと、作成の途中で名簿で準備中のワークスペースがある | 存在しないワークスペース、利用終了の途中のワークスペース、準備中のワークスペースを、それぞれ指定して一覧する | どれも `NotFoundError` |
