# トークンを失効させる

| ID | 前提条件 | 操作 | 期待結果 |
|---|---|---|---|
| TC-token-revokeToken-01 | アプリ連携の権限を持つメンバー。`active` の手動発行のトークンがある | そのトークンを失効させる | 失効したトークンの内容を返す。トークンは `revoked` になり、失効の日時は操作の時刻。`token.revoked` の操作履歴を、対象の名称をトークンの名称として残す。操作履歴はトークンの値を含まない |
| TC-token-revokeToken-02 | アプリ連携の権限を持つメンバー。スクリプトの認証で発行した `active` のトークンがある | そのトークンを失効させる | トークンは `revoked` になる。`token.revoked` の操作履歴を、対象を発行の経路 `device` のトークンとして残す |
| TC-token-revokeToken-03 | アプリ連携の権限を持つメンバー。期限を過ぎた手動発行のトークンがある | そのトークンを失効させる | トークンは `revoked` になる。`token.revoked` の操作履歴を残す |
| TC-token-revokeToken-04 | アプリ連携の権限を持つメンバー。他のメンバーの操作で既に失効したトークンがある | そのトークンを失効させる | 成功として、失効済みであることを示して返す。失効の日時は変わらず、`version` も進まない。操作履歴を追記しない |
| TC-token-revokeToken-06 | アプリ連携の権限を持つメンバー | 存在しないトークンの ID を指定して失効させる | `NotFoundError`。操作履歴を追記しない |
| TC-token-revokeToken-09 | アプリ連携の権限を持たないメンバー。`active` のトークンがある | そのトークンを失効させる | `ForbiddenError`（`PERMISSION_MISSING`）。不足する権限（`integration:manage`）を示す。トークンは `active` のまま。操作履歴を追記しない |
