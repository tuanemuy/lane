# 回答が残らない削除済みフォームの運用設定を削除する

断りが無い限り、設定と回答は、定期ジョブが対象にするワークスペース W のもの。「定期ジョブが設定の削除を実行する」は、W を対象に、このユースケースを呼ぶことを指す。

| ID | 前提条件 | 操作 | 期待結果 |
|---|---|---|---|
| TC-form-disposeRemovedFormSettings-01 | 削除済みフォーム F1 の `removed` の設定があり、F1 の回答は残らない。削除済みフォーム F2 の `removed` の設定があり、F2 の回答が残る | 定期ジョブが設定の削除を実行する | 1 を返す。F1 の設定が無くなる。F2 の設定と回答は残る |
| TC-form-disposeRemovedFormSettings-02 | 削除済みフォーム F の `removed` の設定があり、F の回答は、保持期限を過ぎた S1 だけ | 定期ジョブが、W を対象に「保持期限を過ぎた回答を自動整理する」を実行し、続けて設定の削除を実行する | S1 と、F の設定が、同じ起動で無くなる |
| TC-form-disposeRemovedFormSettings-03 | 前の起動が、削除済みフォーム F の最後の回答を削除した後、設定の削除の前に中断した | 定期ジョブが設定の削除を実行する | F の設定が無くなる |
| TC-form-disposeRemovedFormSettings-04 | 回答の無い現行のフォーム F の `active` の設定と、紐付け待ちの設定 | 定期ジョブが設定の削除を実行する | 0 を返す。どちらの設定も残る |
| TC-form-disposeRemovedFormSettings-05 | W は利用終了の途中。回答が残らない `removed` の設定がある | 定期ジョブが、W を対象に設定の削除を実行する | その設定が無くなる |
| TC-form-disposeRemovedFormSettings-07 | 回答が残らない `removed` の設定 F1 と F2。定期ジョブが設定を読んだ後、F1 の `delete` の確定までに、メンバーが F1 の通知先を変更する | 定期ジョブが設定の削除を実行する | F1 の `delete` は競合し、F1 は残る。定期ジョブは、F1 を同じ起動の中でやり直さず、F2 を削除して、1 を返す。F1 は、次の起動が削除する |
